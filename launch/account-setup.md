# Account Setup

Prepare accounts before launch. Send all launch traffic to the GitHub repo:

https://github.com/kozinkaihatusya/updatesentinel

## Hacker News

- Create an account ahead of launch.
- Use a `Show HN` post.
- Link directly to the GitHub repo.
- Stay available for concise technical replies.

## Reddit

- Create account ahead of launch.
- Comment naturally in r/selfhosted.
- Do not post the product yet during warm-up.
- Do not paste links during warm-up.
- Build some karma.
- Target 2-4 weeks of normal participation if possible.
- On launch, post once with a humble "I built" tone.

## Lemmy

- Pick relevant self-hosted and open-source communities.
- Keep the post concise.
- Link to GitHub.
- Reply to feedback and false positives.

## Dev.to

- Prepare the article draft.
- Link to GitHub.
- Use practical Compose examples.
- Avoid sales language.

## Medium

- Adapt the Dev.to article for a broader technical audience.
- Link to GitHub.
- Keep the core message focused on update hygiene.

## Hackernoon

- Adapt the article with a slightly more narrative opening.
- Link to GitHub.
- Emphasize practical lessons for self-hosters.

## X

- Keep the post short.
- Mention the core checks.
- Link to GitHub.

## LinkedIn

- Use a polished but technical post.
- Avoid corporate launch language.
- Link to GitHub.

## Newsletter

- Send a short note during launch week.
- Explain the update-risk problem.
- Link to GitHub.
- Ask for feedback and real-world false positives.

## Launch Timing

- Launch in the same week across platforms.
- Start with GitHub readiness.
- Use Hacker News and Reddit as primary discovery channels.
- Use articles for longer-term search and reference traffic.
