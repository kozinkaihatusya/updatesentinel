# Paid Support and Early Access

UpdateSentinel CLI is free and open source.

The hosted SelfHostGuard dashboard is not available yet. This page is only for collecting interest and clarifying possible future directions. It does not add cloud functionality to UpdateSentinel, and it does not change the CLI's local, read-only behavior.

UpdateSentinel does not guarantee safe updates. Real backups, changelog review, restore testing, and careful rollout planning are still required.

## Possible Hosted Dashboard

SelfHostGuard may become a hosted dashboard for teams that want:

- scheduled update-risk checks
- scan history
- image tag risk diffs
- alerts for newly introduced latest/floating tags
- GitHub Actions integration
- Slack / Discord alerts
- multi-stack monitoring
- team reports

If this would be useful, open an [Early Access Request](https://github.com/kaibuild/updatesentinel/issues/new?template=early_access_request.md).

## Possible Paid Setup Review

Paid setup reviews may be considered for people who want help reviewing their self-hosted update process.

Possible review areas:

- update strategy review
- Watchtower / Diun / Renovate / Dependabot review
- rollback readiness review
- backup-before-update review
- stateful service update risk review
- written report

If this would be useful, open a [Setup Review Request](https://github.com/kaibuild/updatesentinel/issues/new?template=setup_review_request.md).

## Enterprise and Self-hosting Support

Enterprise or self-hosting support may be considered later. There is no fixed pricing yet, and support is not currently guaranteed.

For now, the goal is to learn whether self-hosters, homelab users, and small teams want this kind of help while keeping UpdateSentinel itself free, open source, local, and read-only.
